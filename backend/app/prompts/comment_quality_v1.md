# Comment quality review — v1

Evaluate whether the comment is concretely grounded, specific, fluent, consistent with the declared voice, novel, truthful, and consistent with the real account identity. Flag generic-only praise, unsupported anchors or claims, fake experience, fake identity, competitor attacks, off-platform contact, duplicates, and intentional typo/obfuscation patterns.

This is a quality and anti-spam check. It must not estimate whether content looks machine- or human-authored and must not optimize evasion. Return only the requested JSON schema.
