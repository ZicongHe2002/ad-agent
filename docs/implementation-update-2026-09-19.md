# 本轮实现与验证（2026-09-19）

测试阶段使用 REVIEW，符合条件的候选进入人工审核；启用 AUTO 后，账号须开启自动发布，活动须关闭逐条审核要求，候选通过检查后进入发布任务。未通过的候选跳过并记录原因，切换模式不会自动批准已有审核任务。

## 已交付

- 新增租户隔离的持久发布设置及 `GET/PATCH /api/v1/system/publishing-settings`，包含模式、自动正文披露及平台通道状态；数据库迁移为 `0004_publishing_settings`。
- 自动正文披露使用真实配置的账号身份与所需 AI 说明，发布前核对正文和记录。重复检测排除该固定说明，同时继续拦截重复正文。
- 发布前再次检查模式、账号及活动开关、品牌与租户状态、质量、风险、披露、能力与每日额度。取消自动模式或关闭所依赖的披露设置后，已排队自动任务会受阻。
- 发布和对账的重试次数及时间由持久状态控制，维护扫描不会无限重新投递耗尽任务；每日额度按 UTC 时间范围统计。
- 修复审核界面缺少披露字段、实时事件流空闲断开、生产环境接受开发密钥、全角字符漏检及平台授权范围检查问题。
- Accounts、Settings、Risk 使用真实后端数据；Comments 增加人工发送任务、原文与目标链接、结果确认回填；Campaigns 可设置是否要求逐条审核。
- 接入可配置的 OpenAI Responses 传输及结构化输出；默认仍为离线 Mock。缺少密钥、模型拒绝或响应不完整不会伪装为真实模型生成成功。
- 独立研究普通登录网页操作，说明其与开放 API 的区别，详见[浏览器评论发送研究](browser-publishing-research-2026-09-19.md)。

## 实际使用边界

小红书、抖音尚未接通真实顶层评论自动发送；新增账号和开启 AUTO 不会改变这一状态。浏览器发送没有实现，本轮也没有发送真实评论。

浏览器运行环境返回 `No browser is available`，浏览器列表为空，因此没有完成前端实际点击或平台登录后的发送验证。模型传输使用模拟 HTTP 响应测试，未调用真实模型。测试使用本地 Python 3.10.5；项目声明与容器目标仍为 Python 3.12+，本轮结果不代替目标运行时、真实 Redis 多进程队列及真实平台验收。

更新现有环境后先运行 `make migrate`。默认保留 REVIEW；实际平台发送通道完成验证前，可使用审核和人工发送记录流程。隔离测试库未修改用户的应用数据库。
